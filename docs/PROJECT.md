# Paper-Context 项目说明

Paper-Context 把本地论文接入 Codex、Claude Code 等支持 MCP 的 AI 工具。你可以在原来的对话里问论文问题，查看支撑回答的原文，并把需要延续的研究背景保存给下次对话。

## 你可以用它做什么

- **从本地文献里找证据。** 导入 PDF、DOCX 或 TXT 后，检索结果会带上可用的标题、章节和页码。全文检索可在本地运行，无需 API Key。配置 embedding 后也可按语义检索。
- **点回答里的引用，回到 PDF 原页。** 在当前开发版中，导入能解析出物理页码的 PDF，启动本地阅读服务，并要求 AI 使用全文检索。点击结论后的「PDF 第 N 页」，就能在浏览器的 PDF.js 阅读器里核对原文。
- **让下一次对话接上进度。** 可以主动保存阅读偏好、研究决定和约束，也可以交接未完成的工作。下一次对话可按任务加载相关记录。

## 从一次提问开始

按[中文快速开始](getting-started.zh-CN.md)完成安装和 MCP 配置，再导入一篇自己的论文。要试用可点击引用，按 [README 的 PDF 原页说明](../README.zh-CN.md#从对话引用打开-pdf-原页)启动阅读服务，然后在对话里问：

> 请用 Paper-Context 全文检索这篇论文，说明作者怎么评估这个方法。把工具返回的引用放在它支撑的结论后，我要点开核对原文。

PDF 直链定位到页。源文件需要留在入库时的位置，旧索引需要先撤销旧入库再重新导入。如果检索结果没有可验证的 PDF 页码，回答仍可标注工具返回的出处。

给 AI 编程助手的仓库上手说明见 [AGENTS.md](../AGENTS.md)。
